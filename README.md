# 📝 To-Do List Project

## 📌 Description

This is a simple To-Do List application developed using Python.

The application allows users to manage their daily tasks through a simple menu-driven interface.

## 🚀 Features

- Add new tasks
- View all tasks
- Check completed tasks
- Delete tasks
- Exit the application

## 🛠️ Technologies Used

- Python
- Lists
- While Loop
- If-elif-else Statements
- User Input
- List Methods
